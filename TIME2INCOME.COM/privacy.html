Information the service handles

  • Account information: email address handled by Supabase Authentication, plus profile name, country, city, role, language, and currency preferences.
  • Provider profiles: skills, category, biography, work preference, service city/country, rates, languages, and portfolio images. Published provider profiles are available to signed-in marketplace users.
  • Optional provider location: if a provider chooses “Set approximate location,” the browser rounds the coordinates to one decimal place before saving them with the provider profile. These coarse coordinates are used to rank nearby providers and are visible to signed-in marketplace users. Providers can remove them from their profile.
  • Search location: a visitor may grant browser location permission to rank providers by distance. That search coordinate is kept in page memory for the current session and is not written by the website to the account or browser storage. Typing a city remains available instead.
  • Marketplace activity: tasks, offers, booking requests and statuses, booking messages, and reviews submitted after completed bookings.
  • Browser preferences: the website stores selected language, currency, and manually entered marketplace city preferences in browser storage.
  • Payments: the code includes an account-activation checkout that uses Razorpay when enabled. Razorpay handles checkout payment details; the website sends payment/order references to Supabase for verification. The marketplace does not currently process payments for service bookings.

Why information is used

Information is used to authenticate accounts, operate profile and task search, support offers and bookings, show reviews, remember browser preferences, and verify account-activation payments when that checkout is available. Do not add a purpose here unless it matches the deployed service.

Marketplace information is shown to other signed-in users as described above.
